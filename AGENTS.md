# Flatterfluff Agent Notes

- Keep the server authoritative for target positions, hits, ammunition, reload timing, streaks, and score.
- Controllers send only aim direction, shoot intent, and reload intent.
- Preserve the 1–6 player limit and both timed and endless lobby modes.
- Keep visible copy localized for German and English.
- Reuse the platform virtual joystick layout unless the interaction model changes materially.
- Do not replace the generated production art with code-drawn placeholders.
- Verify the host at desktop/TV size and the controller at phone size.
- Run `npm run typecheck` and `npm run build` in this package, then platform typecheck/build after syncing.
